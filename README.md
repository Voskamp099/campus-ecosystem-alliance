# 北京校园生态合作联盟

> 连接北京高校、企业与生态伙伴，让实习机会、活动资源与合作需求更快匹配。

北京校园生态合作联盟是一个面向北京高校生态的资源共享与对接平台。平台聚合校园方、企业方和政府方资源，为大学生提供实习实践机会、活动报名、权益福利与创业支持，同时为合作方提供统一的展示窗口和对接通道。

## 平台概览

| 模块 | 说明 |
|------|------|
| 首页 | 联盟动态轮播、合作伙伴展示（高校/企业/政府）、实习岗位与近期活动推荐 |
| 联盟权益中心 | 按四大分类浏览联盟权益：吃喝玩乐、衣食住行、学习提升、就业创业 |
| 生态对接名录 | 高校、企业、政府三方生态伙伴名录，支持按类型筛选与搜索 |
| 对接申请 | 用户可针对名录中的合作方发起对接申请，系统自动生成追踪码 |
| 用户发布 | 注册用户可发布活动和实习实践信息，经管理员审核后展示 |
| 个人中心 | 查看我的对接申请、活动报名记录与投递状态 |
| 后台管理 | 内容管理、审核用户发布、处理对接申请、查看操作日志 |

## 核心功能

**资源聚合与展示**

平台将联盟内的高校、企业和政府资源统一聚合。首页展示合作伙伴矩阵与推荐内容，权益中心按生活场景分类整理联盟权益，生态对接名录提供三方合作方的结构化浏览与搜索。

**双向对接机制**

用户可在生态对接名录中找到目标合作方，填写合作意向并发起申请。每笔申请自动生成追踪码，后续可在个人中心查看状态流转：联盟初审 → 对接评估 → 转交对接 → 对接沟通 → 完成。

**用户发布与审核**

注册用户可以发布活动和实习实践信息，提交后进入待审核状态。管理员在后台审核通过后内容即在前台展示，支持通过和拒绝（附拒绝原因）。

**用户体系**

支持邮箱注册、邮箱验证、密码重置、JWT 登录态维持。用户可完善个人资料、上传头像、查看个人历史记录。

**后台管理**

管理员通过独立后台管理所有站点内容：首页轮播、权益分类、名录信息、合作伙伴等栏目的增删改查与排序，同时审核用户发布、处理对接申请、查看操作日志。

## 技术架构

- **后端**：Node.js + Express，RESTful API
- **数据库**：MySQL（InnoDB + utf8mb4）
- **前端**：原生 HTML/CSS/JS，无框架依赖
- **图片存储**：火山引擎对象存储 TOS（可选，支持本地存储降级）
- **安全**：JWT 鉴权、CSRF 双重提交保护、Helmet 安全头、XSS 过滤、API 限流
- **可观测**：Pino 结构化日志、Sentry 错误追踪、健康检查端点
- **容灾**：MySQL 不可用时自动降级到 JSON 文件存储，保证服务可用

## 部署

支持 Docker Compose 一键部署或直接运行：

```bash
npm install
cp .env.example .env
node server/index.js
```

访问 http://localhost:3000 ，后台管理 http://localhost:3000/admin

详细配置项见 `.env.example`。
